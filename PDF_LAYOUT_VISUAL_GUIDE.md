## 🔧 How It Works

### **React PDF's `fixed` Prop:**

```typescript
// Header appears on EVERY page
<View style={styles.header} fixed>
  <Image src={logoUrl} />
  <Text>Employee Details Form</Text>
</View>

// Content flows across pages
<View style={styles.content}>
  {/* Sections auto-break when page is full */}
</View>

// Footer appears on EVERY page
<View style={styles.footer} fixed>
  <Text>Website: ...</Text>
  <Text>Page {pageNumber} of {totalPages}</Text>
</View>
```

**Magic:**
- `fixed` prop = appears on ALL pages
- Content automatically flows between pages
- Header/footer never move!
